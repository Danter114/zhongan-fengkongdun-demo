# 风控盾 · 演示界面（构建产物）

本目录**整个是构建产物**，不要手改 —— 改源、重跑构建。

```
演示界面\
├─ demo\                    多页版：一页一个目录，页面之间走相对路径
│   ├─ index.html           01 舆情事件采集（输入 → 参数卡 → 采集 → 完成）
│   ├─ board\index.html      舆情看板（从「采集完成」点进来；七节 + 明细 + 口径）
│   ├─ step2\index.html     02 图谱构建
│   ├─ step3\index.html     03 仿真推演（进度跑满后整页铺开报告）
│   │   └─ report.html          引擎真跑出来的报告（ECharts 已内联在这份里，没有旁挂的 echarts.min.js）
│   ├─ step5\index.html     05 深度互动
│   ├─ standalone.html      单文件版：双击就开，五页 + 报告住在一个文件里
│   └─ .nojekyll            空文件
└─ sim.html / sim.js / sim.css   模块三「仿真推演」独立页（接后端那条线，与 demo 同一次构建刷新）
```

打开方式：**双击 `demo\index.html`**（或 `demo\standalone.html`）。
全程不联网：构建时有一道硬闸，扫整棵树，检出任何运行期外链就构建失败。

### 报告源（2026-10-21 起可覆盖）

**默认**读的是交付里冻结的那一份 —— `初赛提交\仿真推演整合\事件\EVT-001\事件配置.json`
的 `out_html`。不传环境变量时构建产物与之前逐位不变。

要把报告换成**满规则重跑 + 最新报告层**产出的那一份：

```
$env:REPORT_SRC = "D:\桌面\mirofish阅读\决赛准备\端到端程序与输出数据\02_事件输出数据\EVT-001\07_满规则重跑_20261021\05_报告\EVT-001_仿真运行可视化报告.html"
node build.mjs "D:\桌面\mirofish阅读\决赛准备\演示界面"
```

覆盖的只是**源**。构建分两种情形，自动判定：

- **源引公网 CDN**（交付里冻结的老报告）：把那 1 行换成本层 `./echarts.min.js`，
  并把这个库一起发出去 —— 两道断言（必须恰好一处外链、换完不许再有 `http` 运行期引用）照旧生效。
- **源已自包含**（`viz_build.py` 带 `REPORT_ECHARTS` 产出的那份，图库已内联）：
  原样照抄、不再落 `echarts.min.js`（上一版留下的旁挂文件会被删掉）。
  判据是"源里有没有内联进来的库"，源坏了照样炸。

当前 `demo\step3\report.html` 与 `demo\standalone.html` 里内嵌的那份报告，**都是这个源**
（42 轮 / 53 帖 / 262 位智能体，1,550,986 B 单文件，断网双击 8 张图全出）。
它与那次跑的产物**逐位相同** —— 拿 `Get-FileHash` 比：
`C06695561C7376C2CCDDC27D89C40F593C5BE73E07A14F5877E4EF9501EE0201`。

这一份报告带 **LLM 三处解读**（`#r22` 交叉解读 / `#r31` 事件链解读 / `#advBox` 综合研判，
各带一行「模型撰写 · 模型名 · 提示词指纹」）。正文在构建时就烘进 HTML 了，所以
`_llm_text.json` **不需要**跟着进交付树；构建产物也不依赖任何 key 或网络。

第 03 页回放的数字（`src\demo\step3\replay.js` 的 `EVENT` / `RECORDER` / `FIRST_RED` / `CUT`）
同源于这一跑的 `事件配置.json` 与 `_viz_data.json`，换源时两处要一起改。
**预警弹窗给的是"首次出现红色预警"那一轮**（`alert.first_round['红色']` = 轮 5），
不是全程峰值（轮 17）—— 峰值回答不了"预案该什么时候启动"。

构建前若换了事件数据，先重跑数据生成器：


**采集窗口是 Day0–Day1，不是整个事件周期。** 采集的产物要整份喂进知识图谱和
仿真推演当初始态，所以 `EVT-001` 只取 t0 起 48 小时内的 3 条；01 页第 3 步里

三支都**真开 Edge 无头浏览器**渲染构建产物（DOM 断言 + 截图 `_shot\p27*_*.png`）：

- **01**：点两次真按钮走完 1→2→3→4 那条链，看板七节与 3 条 / 2 类 / 67% 的对账，
  明细表 3 条原帖链接（抖音 1 + 小红书 2）的 href 落点。
- **02**：`data-node` 必须 263 个（262 位智能体 + 中心）、关系边 3 条、五类角色
  149 / 60 / 29 / 16 / 8，点 t0 发帖人与中心各出一张卡（人设 bio 拿
  `graph.js` 里的原文比，不写死短语 —— 人设是 LLM 写的，措辞会变）。
- **03**：阶段一总数 42、行为记录分母 294；跑满后 ReportPanel 退场、报告 iframe 挂上、
  右上角出「进入深度互动」；红色预警弹窗的**首次触发**（当前 = 轮 5 / S = 0.826 /
  出现时间 2026-05-22 20:00 / G1–G3 / 三档阈值）逐项对账 —— **期望值现读
  `replay.js` 的 `FIRST_RED`，不是写死的**，换事件只改源、探针不用动；
  第 05 页左栏 iframe 指的是同一份 `../step3/report.html`。
